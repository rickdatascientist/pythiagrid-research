The research agenda

Three scientific problems. One coherent direction.

We investigate how agents can retain demonstrably correct work, confront uncertain recovery, and accept community capabilities only when the supporting evidence stands up to scrutiny.

01 / EVIDENCE

Evidence-Carrying Agent Work

Can an independently auditable claim survive several competing attempts, missing proof, and conflicting artifacts without becoming an unsupported success story?

Comparative research pending

02 / RECOVERY

Recoverable Agents Benchmark

How do agents behave when they crash after an effect, lose an acknowledgement, retry an operation, or recover an incomplete state?

Fault-injection study proposed

03 / EVOLUTION

Verified Skill Commons

Can independently contributed skills improve held-out results while respecting permissions, provenance, rollback, and secure admission?

EFAD v0.1: a minimal interoperability contract.

Evidence-First Autonomous Development is not a competing model, agent framework, or orchestration engine. It is a public language for declaring narrow authority, testing evidence, and representing bounded work.

View contractsPublication firewall
  • Authority — explicit actor, action and scope
  • Evidence — predicate, observations and source identity
  • Work state — progress and ANDON stop semantics
  • Capability — typed boundaries and side-effect class

Papers and evidence

Future of Mary and PythiaGrid

A research surface, not a shortcut around safety.

PythiaGrid Research provides an open scientific layer for questions arising from Mary. A researcher's workspace can help explore hypotheses, experiments and manuscripts; a separate Commons experience can accept permission-cleared benchmarks and verified community contributions.

Those are research design directions—not a claim that the full workflow is already deployed. Published contracts, scientific evaluation, and the Mary product each retain independent approval gates.
