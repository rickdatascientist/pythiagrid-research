# Mary Beta Evidence Policy

This repository may receive **beta-only, opt-in, sanitized product evidence** from Mary Kin installations.

The beta evidence schema may contain product surface, PASS/FAIL or Worked Well/Needs Improvement outcomes, coarse latency/duration, retry count, artifact count, admitted model tier, voice availability, and fixed failure codes.

It must not contain prompts, chat content, raw audio, file contents, filenames, local file paths, IP addresses, device/computer names, contacts, emails, account identifiers, or inferred sensitive attributes.

Nothing should be uploaded automatically by Mary. The beta user reviews the GitHub submission before creating the issue. GitHub account metadata is governed by GitHub and is visible according to repository visibility.

This is not the final Mary production privacy or user-data contract.
